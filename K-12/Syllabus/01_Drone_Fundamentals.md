# Drone Fundamentals and Autonomous Flight Programming

Learn how drones work and use Python to program autonomous flight missions with the Tello drone and DJITelloPy.

This course combines drone fundamentals, programming, communication, and practical challenges to help learners progress from understanding a quadcopter to developing their own autonomous flight sequences.

## Course Objectives

By completing this course, learners will be able to:

- Understand the fundamental components and working principles of a quadcopter.
- Explain lift, thrust, roll, pitch, yaw, and altitude.
- Understand how a computer communicates with a Tello drone over Wi-Fi.
- Use DJITelloPy to connect to and control a Tello drone using Python.
- Program takeoff, landing, movement, and rotation commands.
- Create flight sequences and waypoint-based missions.
- Test, debug, and improve autonomous flight programs.
- Develop a basic autonomous mission using predefined routes and checkpoints.

## Course Syllabus

### 01. Introduction to Drones

- What is a drone?
- Types of drones and their applications
- Introduction to quadcopters
- Basic principles of flight
- Applications of autonomous drones

### 02. Understanding a Quadcopter

- Frame and propellers
- Brushless motors and electronic speed controllers (ESCs)
- Flight controller and battery
- Sensors and onboard processing
- How a quadcopter generates movement

### 03. Drone Movement and Flight Fundamentals

- Lift and thrust
- Roll, pitch, and yaw
- Altitude and directional movement
- Coordinate systems and reference directions
- How movement commands translate into drone motion

### 04. Introduction to Tello and DJITelloPy

- Introduction to the Tello drone
- Introduction to the Tello SDK
- What is DJITelloPy?
- Setting up Python and DJITelloPy
- Exploring the DJITelloPy source code and documentation
- Writing and running your first drone program

### 05. Connecting Python to the Drone

- Connecting the computer to Tello Wi-Fi
- Understanding IP addresses and ports
- Introduction to UDP communication
- Sending commands and receiving responses
- Connection checks, timeouts, and basic error handling

### 06. Basic Flight Programming

- Connecting to the drone using DJITelloPy
- Reading basic drone information
- Taking off and landing
- Moving forward, backward, left, and right
- Moving up and down
- Rotating clockwise and counterclockwise
- Understanding command limits and execution delays

### 07. Flight Sequences and Automation

- Combining commands into a flight sequence
- Using loops and functions for reusable movements
- Programming square and rectangular flight paths
- Creating repeated movement patterns
- Introducing waypoints and relative movement
- Testing and debugging flight sequences

### 08. Autonomous Mission Planning

- Breaking a mission into smaller steps
- Defining routes and checkpoints
- Planning movement sequences
- Validating commands before execution
- Handling unexpected responses and interrupted missions
- Separating mission planning from flight execution

### 09. Final Project: Autonomous Drone Challenge

Design and program an autonomous mission that requires the drone to:

- Take off safely.
- Follow a predefined route.
- Visit specified checkpoints.
- Perform selected rotations and movements.
- Complete the mission and land safely.

Learners will plan the route, implement the Python program, test the sequence, and troubleshoot errors.

## Prerequisites

- Basic Python programming knowledge.
- A computer with Python installed.
- A Tello-compatible drone for practical flight activities.
- A safe, open area for testing autonomous flight programs.

Learners should complete the Python Basics for Drone Robotics course first if they have no prior programming experience.

## Safety Guidelines

- Inspect the drone and propellers before every flight.
- Use an open area away from people, obstacles, and fragile objects.
- Maintain a clear landing area and keep the drone within sight.
- Test new programs with short, simple movements before attempting complete missions.
- Understand how to stop a program and safely land the drone.
- Follow applicable local drone regulations and manufacturer guidelines.
