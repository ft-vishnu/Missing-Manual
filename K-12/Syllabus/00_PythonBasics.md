# Python Basics for Drone Robotics

A beginner-friendly Python course covering the programming fundamentals required for drone robotics, autonomous flight, computer vision, interactive drone control, and multi-drone coordination.

Designed for school students, college students, and anyone interested in learning Python through robotics.

## Course Objectives

By completing this course, learners will be able to:

- Write, run, and debug Python programs.
- Work with variables, data types, operators, and conditions.
- Use loops to automate repetitive tasks.
- Store and process information using lists, tuples, and dictionaries.
- Write reusable functions and organize code into modules.
- Handle errors and work with files.
- Understand basic classes and objects.
- Read documentation and use external Python libraries.
- Build simple programs that prepare them for drone programming.

## Course Syllabus

### 01. Introduction to Python
- What is programming?
- Installing Python and setting up VS Code
- Running Python programs
- Basic syntax, comments, and `print()`

### 02. Variables and Data Types
- Variables and naming conventions
- Integers, floats, strings, and booleans
- Type conversion and `type()`
- User input and basic operators

### 03. Conditional Statements
- `if`, `elif`, and `else`
- Comparison operators
- Logical operators: `and`, `or`, and `not`
- Writing decision-based programs

### 04. Loops
- `for` and `while` loops
- The `range()` function
- `break` and `continue`
- Repeating commands and automating tasks

### 05. Python Data Structures
- Lists, indexing, slicing, and list methods
- Tuples and their use cases
- Dictionaries and key-value pairs
- Iterating through collections

### 06. Functions
- Defining functions using `def`
- Parameters and arguments
- Return values
- Local variables and scope
- Breaking programs into reusable functions

### 07. Modules and Packages
- Using `import`
- Python's built-in modules
- Installing external packages using `pip`
- Virtual environments
- Reading documentation and using existing libraries

### 08. Error Handling and Debugging
- Syntax, runtime, and logic errors
- Reading error messages
- Using `try`, `except`, and `finally`
- Debugging and testing programs

### 09. Working with Files
- Reading and writing text files
- Processing simple data
- Saving program outputs and logs

### 10. Introduction to Object-Oriented Programming
- Classes and objects
- Attributes and methods
- Creating a simple class
- Understanding classes used in external libraries

### 11. Final Project: Drone Mission Simulator
- Representing a sequence of drone commands
- Writing reusable movement functions
- Using loops and conditions to control a simulated mission
- Handling errors and validating commands
- Testing a simple autonomous flight sequence without a physical drone

- No previous programming experience is required.
- A computer with Python and a code editor such as VS Code.
- No physical drone is required for this course.
