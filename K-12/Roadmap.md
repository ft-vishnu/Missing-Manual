# K-12 Drone Robotics — Syllabus

This folder contains the syllabi for a series of drone robotics courses built around Python programming and DJI Tello drones.

Each file describes a separate course, including the topics students will learn and the practical work they will undertake.

## Course Syllabi

### 00. [Python Basics](Syllabus/00_PythonBasics.md)

**Learn to program with Python.**

An introduction to Python for beginners, covering variables, data types, conditions, loops, functions, data structures, and basic debugging. This course builds the programming foundation needed for drone robotics.

### 01. [Drone Fundamentals and Autonomous Flight](Syllabus/01_Drone_Fundamentals.md)

**Learn to control a drone using Python.**

Explore drone movement, flight commands, take-off and landing, and automated flight sequences. Progress towards writing Python programs that execute planned drone missions.

### 02. [Computer Vision with Python and Tello](Syllabus/02_Computer_Vision.md)

**Teach a drone to interpret what its camera sees.**

Learn image processing and computer vision using Python and OpenCV. Explore camera feeds, object detection, visual tracking, and camera-based drone projects.

### 03. [Ground Control System Development](Syllabus/03_GCS.md)

**Build your own drone control interface.**

Develop a graphical application using Python and Pygame. Learn to control a Tello drone through a keyboard interface, view its camera feed, and display flight information.

### 04. [Multi-Drone Swarming and Coordination](Syllabus/04_Swarm.md)

**Make multiple drones work together.**

Learn the fundamentals of multi-drone coordination using Python and Tello drones. Explore coordinated commands, simple formations, leader-follower behaviour, and programmed flight sequences.


## Recommended Learning Path

Python Basics → Drone Fundamentals → Computer Vision → Ground Control Systems → Multi-Drone Coordination

The courses progress from programming fundamentals to increasingly advanced drone applications. Simulation and physical drone activities may be used where appropriate.
